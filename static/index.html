How to get your CSV

Expand the platform you use for step-by-step export instructions.

Stripe ▾
  1. Open Stripe Dashboard → Payments.
  2. Filter date range to the last 30 days.
  3. Select Export → choose CSV (or “Download as CSV”).
  4. Before uploading, remove any Customer Name/Email columns.
QuickBooks Online ▾
  1. Go to Reports.
  2. Search for a transactions report (e.g., “Sales by Customer Detail” or “Transaction List”).
  3. Set the date range to the last 30 days and run the report.
  4. Select Export → Export to Excel/CSV, then save as CSV.
  5. Remove any customer-identifying columns before uploading.
Square ▾
  1. Open Square Dashboard → Transactions (or Reports).
  2. Filter to the last 30 days.
  3. Select Export and download the CSV.
  4. Delete any Name/Email columns before uploading.
Authorize.net ▾
  1. Log into Authorize.net → go to Reports.
  2. Open your transaction details report (e.g., Transaction Details / Settlement).
  3. Choose the last 30 days and generate the report.
  4. Select Export → download as CSV.
  5. Remove customer-identifying fields before uploading.
HoneyBook ▾
  1. Open HoneyBook → go to Payments or Reports.
  2. Filter to the last 30 days of payment activity.
  3. Export/download the report as CSV (or export to spreadsheet then save as CSV).
  4. Delete any client name/email columns before uploading.

Privacy First: Remove Customer Name/Email columns before uploading. We only need Date, Amount, Card Type, and Interchange/Fee Code.
